# Código do projeto DoAção

## Módulo Lucas Asth — Sprint 1

Funcionalidade: cadastro e gerenciamento de eventos da comunidade.

### Executar
1. Entre na pasta `Codigo`.
2. Execute `npm install`.
3. Execute `npm run dev`.
4. Abra `http://localhost:3000/comunidade`.

### Testar
- `npm test`
- `npm run lint`
- `npm run build`
